description: Name the current Claude Code session with a short label
---

Name this session so it appears labeled in /sessions and /token-usage.

Run:
```bash
python3 ~/.claude/skills/sessions/name_session.py "$ARGUMENTS"
```

Then confirm to the user: "Session named: <name>"

## Usage examples
- `/name kalmia qwen debug`
- `/name PR review satellite`
- `/name jetson env setup`
