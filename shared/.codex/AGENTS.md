# Global instructions

## 文章の推敲スキル

ドキュメント・PR の説明文・Issue・Slack/Notion への投稿・レポートを書いたり直したりするときは、言語で使い分ける。

- 英語 → `readable` スキル（PR 本文は `light`）。本文は `cat ~/.codex/skills/readable/SKILL.md` で読む
- 日本語 → `yomiyasu:yomiyasu` スキル。本文は `cat ~/.codex/skills/yomiyasu/SKILL.md` で読む

適用外: チャットの返答、コードを直したあとの作業報告、コード、コミットメッセージ、/nippo・/standup など書式が決まっている作業。ファイル検索（rg など）はシンボリックリンクを辿らないので、スキルは検索せず上のパスを直接読む。スキルが入っていない環境ではこのルールを無視してよい。
